# 📊 Data Analysis Tool  

A simple **Data Analysis Web App** built using **Flask, Pandas, Matplotlib, HTML, CSS, JavaScript**.  
This tool allows users to upload a CSV or TXT file and automatically generates insights such as dataset preview, total rows, total columns, missing values, and file size.  

# 🚀 Features  

- Upload **CSV** or **TXT** files  
- Display uploaded dataset in a clean **HTML table**  
- Show dataset summary:  
  - ✅ Total Rows  
  - ✅ Total Columns  
  - ✅ Missing Values Count  
  - ✅ File Size  
- Supports **Data Visualization** using **Matplotlib**  
- Responsive and user-friendly interface  

# 🛠️ Tech Stack  

- **Frontend** → HTML, CSS, JavaScript  
- **Backend** → Python (Flask)  
- **Libraries** → Pandas, Matplotlib, Requests, OS
